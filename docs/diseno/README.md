# Diseño — Reto 11

Árbol de navegación, arquitectura de información, modelo de dominio actualizado y prototipos de alta fidelidad de Pawly. Funcionalidad núcleo del equipo: **Adopciones**.

| Archivo | Contenido |
|---|---|
| `mapa_navegacion.png` | Árbol de navegación por actor (Visitante, Usuario registrado, Administrador) |
| `arquitectura_informacion.md` | Tipos de página, unidades visuales, patrones de navegación, sistema visual, internacionalización, cambios al modelo y trazabilidad caso de uso → pantalla |
| `modelo_dominio.png` | Modelo de dominio actualizado según los datos que muestran las pantallas |
| `prototipo/mobile.html` | 20 pantallas Android 360×640 (mobile first) |
| `prototipo/desktop.html` | 19 pantallas desktop 1440×1024 |
| `prototipo/export/` | Una imagen PNG por pantalla |

Los `.puml` son la fuente de los diagramas y se generan con PlantUML. Los prototipos se abren directamente en el navegador; las fuentes (Bricolage Grotesque y Figtree) se cargan desde Google Fonts.
